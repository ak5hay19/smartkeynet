# Sample data

Small, repo-committable samples (e.g. ~100 rows) go here so CI and
teammates without the full downloads can still run tests
(split.md §3, "Commit a tiny sample... for tests").

Do not commit full RT-IoT2022 or Q-OPSEC CSVs here — see the licensing
note in `data/README.md`. Samples committed here should be small
enough to be an obvious excerpt, not a redistribution of the full
dataset.
